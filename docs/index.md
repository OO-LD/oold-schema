<h2 class="oold-hero__heading">Who it is for</h2>

<div class="grid cards oold-hero__audiences" markdown>

- :material-graph-outline:{ .lg .middle } **Linked data developers**

    ---

    For developers already familiar with the Semantic Web who want to make
    their projects more efficient and sustainable with reusable data models.

- :material-account-group-outline:{ .lg .middle } **Complex data practitioners**

    ---

    For anyone working with complex data processing, such as civic tech
    practitioners, who wants to get started with data interoperability, so
    that humans and machines can work hand in hand to express what data means.

</div>
