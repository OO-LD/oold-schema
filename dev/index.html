OO-LD Schema¶

OO-LD is a data interoperability framework that bridges the gap between human- and machine-readable data.

Introduction Guide Use Cases Specification

Who it is for¶

  • Linked data developers

    For developers already familiar with the Semantic Web who want to make their projects more efficient and sustainable with reusable data models.

  • Complex data practitioners

    For anyone working with complex data processing, such as civic tech practitioners, who wants to get started with data interoperability, so that humans and machines can work hand in hand to express what data means.

We target domains where data-driven innovation is limited by lack of interoperability. ¶

  • Civic Tech

    Governmental form processing (eGovernment)

  • Research

    Scientific data validation (FAIR data)

  • Industry

    Manufacturing supply chain verification (Digital Product Passport)
